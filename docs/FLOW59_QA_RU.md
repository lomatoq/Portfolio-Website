# FLOW59 — изменения и проверка

Основная причина: вставка WORK HISTORY меняла высоту main, но ResizeObserver обновлял только контроллер скролла. Рендерер сохранял прежние координаты сцен. В 1440×900 расхождение составляло 574 px. Теперь инвалидируются оба кеша.

Остановки используют общие точки из director.js. На входе остаточные импульсы отбрасываются до полностью раскрытой сцены и короткого показа (360 мс); при непрерывном жесте движение возобновляется через 950 мс после раскрытия. Обратное направление отменяет задержку сразу. Очередь отложенных импульсов не создаётся. Native scrollbar, программная навигация и reduced motion не используют эту задержку.

Проверено в локальном headless Chrome:

- 1440×900 и 390×900: все 24 точки (5 интро и 19 кадров галерей) полностью раскрыты, pin находится у верхней границы экрана.
- Серия сильных wheel-импульсов сохраняет первое интро; новый жест доходит до первого кадра; разворот сразу снимает задержку.
- Реальное открытие Playgendary кликом, затем Polysphere; скрытые полосы прокрутки; прокрутка медиа не двигает страницу.
- Escape закрывает сначала медиа, затем родительский кейс; позиция страницы сохраняется.
- WORK HISTORY получает blur(18px) за открытым кейсом.
- Ошибок JavaScript в этих сценариях нет.
- Дополнительно осмотрен попап в 390×844; горизонтального переполнения нет.

Это проверка Chromium и эмуляции размеров экрана, не физического телефона или трекпада. Демонстрационное содержимое исходного архива сохранено.

Для повторения: установить Playwright и Chrome, запустить `python -m http.server 4190` из корня проекта и выполнить `node tests/flow59.cjs`. По умолчанию тест использует http://127.0.0.1:4190/; переменная FLOW59_URL позволяет задать другой адрес. Скриншоты создаются в текущей папке.
