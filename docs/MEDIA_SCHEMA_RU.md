# Медиа-слой FLOW58

## Где находятся данные

`content/media.json` содержит объект `items`. Ключ соответствует существующему `data-case`. Например, ключ `chick` переключает выбранные ячейки Chick Fiesta в company-case на длинный визуальный кейс. Карточки без ключа в этом реестре продолжают открываться старым способом.

Изменение JSON само по себе не изменяет уже встроенный HTML. После редактирования запустите `python rebuild.py`.

## Одно длинное изображение

Пример конфигурации; файлы по этим путям нужно добавить самостоятельно:

```json
{
  "version": 1,
  "items": {
    "chick": {
      "type": "long-image",
      "title": "Chick Fiesta",
      "eyebrow": "SPRIBE / VISUAL STORY",
      "src": "assets/chick-case.webp",
      "width": 1600,
      "height": 9000,
      "alt": "Описание визуального содержания работы",
      "demo": false,
      "description": "Короткое введение в проект.",
      "sections": [
        {"title": "Моя роль", "text": "Подтверждённая роль и конкретная зона ответственности."},
        {"title": "Задача", "text": "Контекст, ограничения и принятые решения."}
      ],
      "tags": ["UI / UX", "Motion"],
      "note": "Кредиты и разрешения на публикацию."
    }
  }
}
```

Размеры должны соответствовать реальному файлу: это резервирует правильную высоту до загрузки. Изображение не обрезается в короткий cover; оно сохраняет отношение сторон и прокручивается по высоте.

## Лента сегментов

Для очень длинного кейса можно использовать `images` вместо `src`:

```json
"images": [
  {"src": "assets/chick-01.webp", "width": 1600, "height": 3000, "alt": "Общий вид"},
  {"src": "assets/chick-02.webp", "width": 1600, "height": 4200, "alt": "Детали интерфейса"}
]
```

Первый сегмент загружается сразу, последующие — лениво. Ширина единая, промежутков между сегментами по умолчанию нет. Это та же визуальная лента, а не набор всплывающих окон. Не добавляйте гигантское изображение в каждую карточку страницы: медиаматериал создаётся только при открытии верхнего слоя и удаляется при закрытии.

## Видео

```json
"dragon": {
  "type": "video",
  "title": "Dragon Heist",
  "eyebrow": "SPRIBE / MOTION",
  "src": "assets/dragon-reel.mp4",
  "poster": "assets/dragon-poster.webp",
  "demo": false,
  "autoplay": true,
  "muted": true,
  "loop": true,
  "description": "Описание последовательности.",
  "sections": [{"title": "Моя роль", "text": "Роль, инструменты и кредиты."}]
}
```

`autoplay`, `muted`, `loop` включены по умолчанию; каждый можно выключить через `false`. При запуске со звуком браузер может потребовать пользовательское подтверждение — есть fallback Play. Видео имеет `controls` и `playsinline`; при закрытии оно ставится на паузу. Поддержка конкретного кодека зависит от браузера; практичный вариант для проверки — H.264 MP4. Документация по политике автозапуска: https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay

Уберите `demoVideoSelector` из постоянного контента: он нужен только для использования уже встроенного синтетического клипа в этом прототипе. `demo: false` убирает демонстрационные подписи. Локальная подмена доступна в режиме автора. Контекст, роли и достижения должны быть заполнены реальными подтверждёнными данными.

## Открытие из нового элемента

```html
<button type="button" data-media-open="chick">Открыть визуальный кейс</button>
```

Или через API после загрузки сайта:

```js
NocturneMedia.register('new-work', {
  type: 'long-image',
  title: 'New work',
  src: 'assets/new-work.webp',
  width: 1600,
  height: 7000,
  alt: 'Описание',
  demo: false,
  sections: []
});
NocturneMedia.open('new-work', document.activeElement);
// Promise закрытия:
await NocturneMedia.close();
```

Для автоматического переключения именно существующих company-cells используется их `data-case`, только внутри `.case-company` / `.case-works`. Верхние карточки проекта на основной странице не перехватываются этим правилом.

## Поведение слоёв

Viewer — отдельный `<dialog>` в top layer. HTML и внутренний scroll родительского кейса не заменяются. Скролл страницы фиксируется, видео под слоем ставятся на паузу. Escape закрывает верхний слой, а не всю цепочку кейсов. После закрытия восстанавливается focus на открывшем элементе без прокрутки страницы к нему.

На desktop `.mv-media` — собственный нативный скроллер, `.mv-notes` — колонка рядом. До 760 px layout становится вертикальным скроллером; изображение идёт раньше текста. Появление notes привязано к достижению нижней части изображения через IntersectionObserver, без таймера, который блокировал бы свайп.

Открытие и закрытие используют WAAPI; повторное открытие отменяет старую анимацию без stale callbacks. Размер окна меняет раскладку viewer; underlying expanded company refit выполняется за затемнённой подложкой. Reduced motion сокращает анимацию, не скрывая текст.

## Локальная проба файлов

Включите существующий режим автора в меню инструментов и откройте медиакейс. Кнопка `Replace demo locally` создаёт временный object URL. Файл не отправляется на сервер и не записывается в проект. При повторной замене старый URL освобождается. После перезагрузки снова используется `media.json`. В обычном просмотре элементы подмены скрыты.

Демонстрационный `long-image` без `src` / `images` отображается как адаптивная HTML-лента с иллюстрациями и подписями. Настоящий длинный файл или сегменты по-прежнему отображаются в исходных пропорциях. Кнопка внизу возвращает в родительский проект, а `Project details` переводит фокус к пояснениям и на телефоне прокручивает к ним.

Для одного самостоятельного HTML без соседних assets используйте data URL, либо встройте материалы отдельным упаковщиком. `rebuild.py` упаковывает CSS/JS/JSON, но **не** конвертирует файлы из `assets/` в data URL автоматически. При относительных путях передавайте пользователю весь архив с assets, не только index.html.
