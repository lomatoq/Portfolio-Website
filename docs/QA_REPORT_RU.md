## Ограничения

WebGL probe не смог создать контекст: режим canvas2d, состояние blocked_environment. Это **не** успешно пройденная проверка WebGL. Исходные шейдеры не переписаны.

Проверки выполнены в Chromium. Физический трекпад, настоящий Safari/iPhone, аппаратный WebGL и FPS на устройстве пользователя не проверены. Внешние шрифты при проверке были отключены. file:// заблокирован политикой среды, использовался полный HTML через set_content.

Статические pose-проверки не доказывают плавность движения. Проверка реакции за два предъявленных кадра не является универсальной гарантией latency в миллисекундах. Полные входы в пять глав проверяются отдельными wheel-сценариями, между которыми используется instant setup.
