# Исследование: что использовано в FLOW58

Дата проверки публичных источников: 17 сентября 2026.

## Непрерывный scroll вместо презентационного Observer-паттерна

Lenis описывает единый цикл для синхронизации native scroll, WebGL и анимаций; блокировка ввода до достижения цели вынесена в отдельный параметр `scrollTo.lock`. Вложенные скроллеры предусматривают собственный native scroll. Это полезные ориентиры для данного сайта: не смешивать несколько владельцев позиции и не путать плавность с запретом на дальнейший ввод.

Источник: https://github.com/darkroomengineering/lenis — разделы Features, Custom raf loop, Methods, Nested scroll.

В FLOW58 **не подключён Lenis**, и его код не скопирован в сборку. Существующий API NocturneScroll сохранён, а его модель ввода и движения заменена самостоятельным контроллером. Это позволяет не наслаивать сторонний scroll engine на существующий rAF и sticky-архитектуру.

## Визуальный ориентир

Авторский разбор Codrops “Getting Creative with Infinite Loop Scrolling” показывает построение непрерывного motion-потока с Lenis и GSAP на примере эффекта Bureau DAM. Для нашей задачи важна синхронизация формы и прокрутки, а не сама бесконечная петля: в портфолио сохранены начало, конец и обычная навигация.

Источник: https://tympanus.net/codrops/2023/01/11/getting-creative-with-infinite-loop-scrolling/

Это исследование опубликованного разбора/кода, а не измерение настоящего сайта Bureau DAM на физическом трекпаде. Клонирование чужого дизайна не выполнялось.

## Почему не обязательный scroll-snap-stop для всех карточек

CSS scroll-snap-type задаёт строгость snap-поведения. Для длинной сцены со sticky-галереями snap-точки должны соответствовать фактическим позам, а не случайным границам DOM-секций. В FLOW58 мягкое доведение реализовано на уровне того же playhead, который управляет сценой; нативный CSS snap не работает параллельно с ним.

Источник: https://developer.mozilla.org/en-US/docs/Web/CSS/scroll-snap-type

Выбор мягкого, прерываемого доведения и отказ от обязательных карточных стопов — проектное решение по текущему запросу пользователя, а не утверждение, что любой один инструмент лучше другого.

## Медиа поверх существующего кейса

Нативный modal dialog предоставляет top layer и делает фоновый документ неинтерактивным. Дополнительно реализованы сохранение scroll, возвращение focus, корректное закрытие верхнего слоя и остановка видео. Для видео учитывается политика автозапуска: используется muted playback с явной Play-кнопкой при отказе браузера.

Источники:
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog
https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay

## Что является нашим решением, а не фактом из источников

Параметры 300/420 мс, локальное сопротивление входа 0.48, зоны магнитного доведения, пружинный интегратор с сохранением скорости, ограничение дальности накопленной цели, линейный transition master и размещение media/notes подобраны для текущей геометрии Flow57. Их функциональное поведение проверяется тестами в архиве. Они не являются универсальным «стандартом дорогих сайтов» и не доказывают целевой FPS на любом устройстве.
