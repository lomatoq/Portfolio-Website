# NOCTURNE R14 — spec

## Главная цель итерации

Сейчас сайт уже стал сильнее по атмосфере, но ему всё ещё не хватает трёх вещей:

1. **более живого motion design**, 
2. **более цельной визуальной физики UI**, 
3. **более красивой связки между состояниями**. 

То есть в этой итерации мы не “чиним по мелочи”, а делаем следующий уровень polish:

-  меньше жёстких геометрических анимаций, 
-  больше органики, инерции, блюра, затухания, distorting transitions, 
-  меньше лишних линий и технических разделителей, 
-  более премиальные карточки и попапы, 
-  более цельный свет и flow по сцене.

# 1. Верхняя навигация / центральный slider bubble

## Что меняем

-  Тёмная подложка должна быть **не на весь top bar**, а **только под центральным сегментом-слайдером**. 
-  Это должна быть **мягкая локальная градиентная подложка**, не прямоугольный жёсткий блок. 
-  Когда под слайдером появляется яркий/контрастный контент, эта подложка должна: 
  -  очень мягко расширяться, 
  -  чуть сильнее затемнять фон, 
  -  слегка подблюривать то, что под ней. 

## Поведение

-  Базовое состояние: компактный dark gradient pod за bubble. 
-  Усиленное состояние: если в зоне behind bubble высокий контраст/яркость, подложка чуть расширяется и усиливает separation. 
-  Всё происходит плавно, без заметного переключения состояния. 

## Done when

-  Верхний navigation bubble читается чисто всегда. 
-  Нет ощущения, что затемнение “лежит поверх всей шапки”. 
-  Bubble остаётся главным, а фон — вторичным.

# 2. Удаление лишних разделителей

## Что меняем

-  Убрать по проекту почти все тонкие технические линии. 
-  Оставить только те, которые реально работают как: 
  -  progress line, 
  -  active scroll indicator, 
  -  purposeful UI marker. 

## Поведение

-  Все декоративные separator lines, которые не несут функции, либо убрать полностью, либо сделать почти невидимыми. 
-  Особенно в project sections и popup layouts. 

## Done when

-  Интерфейс выглядит чище. 
-  Ничего не режет глаз “сеткой”. 
-  Остаются только meaningful line-elements.

# 3. Scroll to Explore indicator

## Что меняем

-  Убрать текущую тонкую полоску. 
-  Сделать **более красивый анимированный cue**: 
  -  мягкий, 
  -  живой, 
  -  subtle, 
  -  согласованный с общей эстетикой. 

## Возможный характер

-  Это может быть: 
  -  жидкий vertical pulse, 
  -  стеклянный маркер, 
  -  мягко текущий световой drop, 
  -  мини-глиф со сдвигом вниз и fade-trail. 

## Done when

-  Индикатор читается как “scroll down”. 
-  Он выглядит не технически, а атмосферно. 
-  Не спорит с hero.

# 4. Экран выбора проектов — moon flash / light burst

## Что меняем

На экране **“Not just what you see”** добавляем световое событие:

-  вспышка луны, 
-  резкая подсветка тумана, 
-  яркое краткое высветление травы, 
-  этим светом “прикрывается” выход/вход следующих элементов. 

## Поведение

-  При входе в секцию свет не просто статично висит. 
-  Должен быть controlled flare / bloom event: 
  -  сначала вспышка, 
  -  потом короткое расширение света, 
  -  потом спад до нормального состояния, 
  -  поверх/после этого мягко материализуются project nodes. 

## Done when

-  Переход в проектную секцию ощущается как сцена, а не просто смена экрана. 
-  Появление карточек становится более кинематографичным.

# 5. Organic expansion frame для project hero

## Что меняем

На блоках типа **Beyond Pixels** текущая расширяющаяся рамка слишком геометрично скейлится.

Нужно:

-  сделать её **размытой**, 
-  сделать её **живой**, 
-  добавить **organic distortion**, 
-  убрать ощущение простого scale-box. 

## Поведение

-  Рамка появляется как энергетическая форма: 
  -  слегка distorted, 
  -  с мягким flow по краям, 
  -  с еле заметной нестабильностью контура, 
  -  с blur/alpha breathing. 
-  Она не должна быть идеально математической в переходе. 

## Done when

-  Рамка ощущается как живая оболочка. 
-  Вход блока становится дороже визуально.

# 6. Gallery cards внутри проектов

## Что меняем

У карточек в проектных галереях:

-  убрать внутренний искусственный border/frame между контентом и краем карточки, 
-  убрать внутренний padding вокруг медиа, 
-  контент должен идти **почти до самого внутреннего края stroke-карточки**, 
-  добавить лёгкое ощущение парения, 
-  сделать контур более “энергетическим”. 

## Поведение

-  Структура карточки: 
  -  внешний stroke / shell остаётся, 
  -  внутренний лишний frame исчезает, 
  -  image/video/content sits edge-to-edge внутри usable area. 
-  Сзади у карточки — очень лёгкий halo/glow, будто она чуть парит. 
-  Контур карточки должен иметь мягкую изменяющуюся энергию: 
  -  не постоянно дёргаться, 
  -  а едва жить. 

## Done when

-  Карточки выглядят легче и современнее. 
-  Контент выглядит крупнее и важнее. 
-  Нет ощущения “карточка внутри карточки”.

# 8. Анимация ухода одного проекта и прихода другого

## Что меняем

Сейчас уходящий проект недостаточно исчезает и слишком прямолинейно уезжает.

Нужно:

-  довести альфу до реального ухода, 
-  сделать уход типографики, subtitle, labels, supporting text — **анимированным и staged**, 
-  добавить blur dissolve, 
-  добавить буквенный/словесный распад. 

## Поведение

Уходящий проект:

-  не просто едет и чуть меркнет, 
-  а: 
  1.  начинает терять резкость, 
  2.  тексты уезжают по словам/частям, 
  3.  всё мягко уходит в alpha + blur + лёгкую хроматическую декомпозицию, 
  4.  только потом полностью уходит. 

Входящий проект:

-  появляется тоже staged: 
  -  first light, 
  -  then shell/frame, 
  -  then headline, 
  -  then supportive content, 
  -  then media. 

## Done when

-  Нет остаточного ghosting прошлого проекта. 
-  Переход ощущается направленным и продуманным.

# 9. Hero text / заголовки проектов: вход и выход

## Что меняем

Все project headers и subheaders должны:

-  красиво входить, 
-  красиво уходить, 
-  не просто fade/translate, 
-  а иметь литературную motion-структуру. 

## Поведение

### Вход:

-  headline появляется по словам, 
-  слова могут чуть отличаться по таймингу, 
-  лёгкий rotate / blur to sharp, 
-  мягкое settle в конце. 

### Выход:

-  либо пословно, 
-  либо покомпонентно, 
-  с расплыванием, 
-  с уменьшением контраста, 
-  с уходом в альфу. 

## Done when

-  Заголовки ощущаются как часть motion language, а не просто как текстовый слой.

## Что меняем

Нужно:

-  убрать пустое “ничто”, 
-  сделать связку перехода более плавной, 
-  ввести промежуточное световое/атмосферное состояние. 

## Поведение

Между project section и Bento:

-  предыдущий блок красиво растворяется, 
-  появляется промежуточный atmospheric stage, 
-  title Bento секции materializes постепенно, 
-  затем карточки вылетают/вплывают. 

## Done when

-  Нет пустой мёртвой паузы. 
-  Bento section входит как логичное продолжение.

# 11. Bento cards — motion, композиция, внутренние паддинги

## Что меняем

-  Карточки Bento должны появляться динамичнее. 
-  Внутренний контент тоже должен заполнять area плотнее. 
-  Внутренний padding между контентом и stroke уменьшить до нуля или почти нуля. 
-  Сами карточки можно сделать чуть более живыми по перспективе. 

## Поведение

### Вход карточек:

-  staggered reveal, 
-  не одинаковый у всех, 
-  более мелкие карточки могут иметь чуть более активную chromatic motion, 
-  может быть лёгкий fly-in / phase-shift / soft perspective drift. 

### Внутри карточки:

-  media/content ближе к краям, 
-  только stroke ограничивает форму, 
-  лишнего пустого поля нет. 

### Взаимодействие:

-  при пролистывании карточки могут слегка менять perspective, 
-  чуть откликаться на скорость и направление scroll. 

## Done when

-  Bento выглядит живее. 
-  Контент в карточках не “утоплен”. 
-  Визуально всё плотнее и дороже.

# 12. Инерция для scroll и motion во всём проекте

## Что меняем

Добавить ощущение инерции везде, где сейчас всё двигается слишком линейно.

## Входит сюда

-  листание проектов, 
-  движение галерей, 
-  движение Bento, 
-  анимации шапок, 
-  reveal/hide блоков, 
-  hero exit, 
-  river/light interactions. 

## Поведение

-  Элементы не должны стартовать и останавливаться “цифрово”. 
-  Должны быть: 
  -  acceleration, 
  -  drag, 
  -  settle, 
  -  residual easing. 

## Done when

-  Всё двигается с ощущением массы, а не как по switch-case.

# 13. Hero name exit при первом скролле

## Что меняем

Когда мы уходим с первого экрана вниз, имя должно не просто исчезать, а **красиво распадаться**.

## Поведение

-  Буквы: 
  -  поочерёдно теряют устойчивость, 
  -  слегка разлетаются, 
  -  уменьшаются, 
  -  уходят в alpha, 
  -  возможно слегка теряют фокус и glow. 
-  При этом общий жест должен быть собранный, а не chaotic glitch. 

## Done when

-  Первый экран красиво отпускает пользователя дальше. 
-  Hero не просто “отключается”.

# 14. Редизайн popup / work popup

## Что меняем

Текущие popup’ы:

-  недостаточно glass, 
-  layout слабый, 
-  не ощущаются премиальными, 
-  по структуре недостаточно интересны, 
-  слишком отделены от карточек, из которых открываются. 

## Новая цель

Сделать popup:

-  glassy, 
-  лёгким, 
-  цельным, 
-  пространственным, 
-  с реально красивым layout. 

## Новая структура popup

### Верх:

-  hero media / image / visual block на большую ширину или почти full-width, 
-  красиво framed, возможно bento-like content clusters. 

### Инфоблок:

-  крупный title, 
-  аккуратный secondary text, 
-  project metadata, 
-  tags/disciplines, 
-  visual links / subitems, 
-  supporting cards or mini bento elements. 

### Материал

-  полупрозрачный, liquid-glass-like, 
-  с блюром, 
-  со светом, 
-  с аккуратной глубиной. 

## Поведение открытия

Когда жмём на карточку:

-  карточка не просто исчезает и popup отдельно появляется, 
-  должен быть **fake continuity transition**: 
  -  карточка становится источником, 
  -  масштабируется / подхватывается, 
  -  деформируется, 
  -  и превращается в popup sheet. 
-  То есть ощущение, что popup вырос из карточки. 

## Поведение закрытия

-  popup собирается обратно мягко, 
-  если уместно — возвращается к карточке, 
-  всё uniform c остальными transition rules. 

## Done when

-  Popup ощущается частью той же системы. 
-  Layout красивый, чистый и премиальный. 
-  Переход карточка → popup выглядит магично.

# 15. Светящаяся река / energy river

## Что меняем

Это отдельный важный слой сцены.

## Новая логика

-  Река не должна “приходить” к карточке сразу в момент её появления снизу. 
-  Она должна достигать зоны карточки **чуть позже**, когда блок уже поднялся примерно на **15–20% выше по экрану**. 
-  Перед карточкой река: 
  -  немного гаснет, 
  -  расплывается, 
  -  теряет часть плотности. 
-  После карточки — тоже мягко угасает, как в начале/конце своего следа. 
-  Вокруг блока с работой этот свет как бы: 
  -  обволакивает, 
  -  чуть подсвечивает карточку, 
  -  мягко разливается блюром и альфой. 

## Поведение

-  Река не “втыкается” в карточку. 
-  Она обходит/обтекает её как энергия. 
-  Карточка красиво подхватывает это свечение. 

## Done when

-  Световой поток и карточки ощущаются связанными. 
-  Появляется эффект живой сцены, а не просто декоративной полосы.

# 16. Hover для play/action buttons

## Что меняем

Сейчас кнопки норм, но hover можно сделать лучше.

## Поведение

-  При hover: 
  -  не белеют грубо, 
  -  становятся немного менее прозрачными, 
  -  получают более богатую реакцию материала, 
  -  лёгкий сдвиг света, 
  -  micro-depth reaction, 
  -  возможно subtle pulse. 

## Done when

-  Кнопки ощущаются более дорогими и интерактивными. 
-  Hover не выбивает их из общей палитры.

# Что **не трогаем** в этой итерации

Чтобы не расползтись:

-  не меняем общий арт-дирекшн, 
-  не меняем базовую структуру сайта, 
-  не делаем редизайн типографики заново, 
-  не переделываем все кейсы по контенту, 
-  не добавляем новые разделы, 
-  не разгоняем эффекты до визуального мусора. 

Цель — **polish, continuity, motion quality, popup quality, scene quality**.

# Критерии успеха итерации

После этой итерации должно быть ощущение, что:

-  сайт **не просто красивый**, а **живой**; 
-  переходы между блоками ощущаются **режиссированными**, а не техническими; 
-  карточки и попапы стали **премиальнее**; 
-  Bento section перестал быть “просто следующим экраном”; 
-  верхний UI стал **чище** и **точнее**; 
-  световая река и карточки наконец начали **работать вместе**; 
-  весь проект стал ближе к **interactive motion portfolio**, а не к просто красивому лендингу.
