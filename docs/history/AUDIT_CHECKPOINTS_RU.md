# Прокрутка по чекпойнтам — 16.09.2026

Запрос: фиксированные смысловые остановки и плавный переход с разгоном/торможением вместо свободной остановки в произвольном состоянии.

Изменены effects.js (обработка жестов, остановки и синусоидальная интерполяция) и director.js (координаты сцен и кадров галерей). index.html пересобран.

При 1440x900 получены 40 остановок: первый экран, 8 работ, выбор проектов, 5 сцен с отдельными кадрами галерей, дополнительные проекты, индекс и контакты. Соседние точки одной строки Bento объединяются. Геометрия пересчитывается при изменении размеров и загрузке шрифтов.

Один поток событий колеса = один переход; события во время перехода не ставятся в очередь. Пауза между жестами — 190ms. Длительность соседнего перехода 850–1400ms в зависимости от расстояния. Easing: (1-cos(pi*t))/2. Дальние навигационные ссылки также перемещают страницу непрерывно, без прежнего скрытого мгновенного прыжка. После ручного перетаскивания полосы прокрутки страница доводится до ближайшей точки.

Исключения: внутри диалога, полей и локальных контролов остаётся обычное управление. Горизонтальное перетаскивание галереи сохраняется. Ctrl+колесо сохраняет масштабирование. В reduced motion остаётся нативная прокрутка без обязательных остановок. Тач-контролы canvas/video сохраняют собственные жесты.

Проверено в headless Chrome 152 с WebGL2, 1440x900 и 390x844: один длинный жест — одна остановка, монотонное движение, обратный ход, клавиатура, независимый скролл диалога, остановка галереи, мобильный свайп через Chrome DevTools Protocol, reduced motion. Ошибок JS нет. Скриншоты остановок проверены визуально. Данные: qa/checkpoint-results.json; запуск: node qa/checkpoint-check.cjs (требует установленный Playwright, путь к библиотеке указан в начале скрипта).

Это изменение управления прокруткой, а не доказательство стабильных 60fps на любом GPU. Физический тачпад и физический телефон отдельно не проверялись.
