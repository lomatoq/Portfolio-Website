# Галерея и динамика поп-апов — 16.09.2026

## Изменения

loader.css: убрана маска rail-window, ограничивавшая область отрисовки теней карточек. Под controls отдельный градиент: alpha 0 сверху, .10 на 24%, .48 на 66%, .78 внизу. Он привязан к controls, не заливает всю галерею. Фильтр материала окна постоянный blur(12px), вместо большого blur(38px); переключения материала в конце анимации нет. Блюр фона 6px сохранён.

continuity.js: открытие использует 61 отсчёт аналитической затухающей пружины, damping ratio .663, omega 12, длительность 980ms. Максимальный ход примерно 1.062. Закрытие за 720ms сужает clip-path и перемещает его к видимой исходной карточке работы. Контент не масштабируется. Для остальных источников форма собирается и смещается вниз. Блюр контента начинается во второй половине; небольшая волна размытия карточки проходит в конце и затухает. Быстрый Escape во время открытия сохраняет текущую позу до начала закрытия.

renderer.js: устранено принудительное ограничение отрисовки поля до 10fps при открытом диалоге. К временному возврату добавлен параметр returnBlur: смягчает край и отражения исходной карточки без отдельного offscreen прохода. В покое параметр равен нулю, исходные формулы материала сохранены (прибавления 0, множители 1). Масштаб карточки при возврате не меняется.

## Проверка

Chrome 152.0.7977.83, WebGL2, desktop 1440x900 и mobile 390x844. Локальный сравнительный прогон: p95 интервала кадров 25.1 → 20.8ms; кадров более 50ms — 4 → 3. Во время появления поле раньше обновилось 8 раз за 838ms, теперь 90 раз за 1075ms. Это один локальный прогон, не гарантия частоты на другом устройстве.

Измеренный overshoot открытия: -55.5px относительно конечной позиции. Во всех отсчётах закрытия scale=1, меняются только перенос, маска и прозрачность. Ошибок JavaScript и ошибок инициализации шейдеров в проверке не было. Изображения: qa/controls-after.png, qa/return-mid.png. Данные кадров: qa/return-results.json; сценарии: qa/return-check.cjs и qa/return-mobile-check.cjs.

Основная версия заменена только после проверки, с резервной копией предыдущих исходников. Safari и физический телефон не проверялись.
