# Чувствительность и рамка — 16.09.2026

Исправлена блокировка wheel во время перехода. Начальный порог 10px вместо 18px, повторный 65px с ограничением 105ms между продвижениями. Повторный ввод продвигает цель дальше; при переназначении сохраняются текущая позиция и скорость (монотонный кубический Hermite с нулевой конечной скоростью). Для старта с места сохранён синусоидальный easing. Одиночный переход 460–900ms вместо 850–1400ms. Цель ограничена тремя высотами экрана впереди, чтобы жест не создавал длинную очередь после отпускания. Повтор клавиши и продолжительный вертикальный свайп также принимаются во время движения.

Рамка: четыре независимых path заменены общим SVG path и четырьмя use; viewBox обновляется только при изменении размера. Удалён внешний анимируемый фильтр на полноэкранной рамке. Вместо вложенного blur 12px + 3px используются фиксированные blur 4px / 1.5px на отдельных штрихах. Деформация, оттенки и мягкая подсветка сохранены; материал карточек не изменялся.

Chrome 152, WebGL2, 1440x900: wheel 12px запускает движение; серия шести событий проходит несколько остановок монотонно (599,749,995,1292,1560,1786; конечная позиция 2080), обратный ввод работает. Воспроизведено место V-ICE: третий кадр переходит на четвёртый по wheel 24px. У рамки один path, четыре use и отсутствует общий filter. Скриншот проверен визуально, ошибок JS нет. Это проверка поведения и сокращения работы рендера; абсолютная частота кадров на любом GPU не гарантируется. Данные: qa/speed-results.json; сценарий: qa/speed-check.cjs.
