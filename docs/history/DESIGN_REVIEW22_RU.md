# Дизайн-направление после case22

17 сентября 2026. Исследование и предложения; реализация не изменялась.

## Решение

Оставить единую сцену: ночная трава, лунный свет, асимметричное стекло и очень редкие цветные предметы. Главный акцент — работа автора, второй — типографика, третий — материал. Цветной загрузчик должен выглядеть прологом этой сцены. Не добавлять отдельный визуальный язык для каждой секции.

## Что видно на локальных кадрах

Проверены `case22-desktop.png`, `case22-gallery.png`, `case22-icons.png`, `case22-loader.png`. Это статические кадры: по ним нельзя подтвердить плавность движения.

В раскрытом Playgendary силуэт стекла выразительный, но нижние изображения обрезаны зоной размытия. Строки PERIOD и CHAPTER дублируют годы, а указатель VIEW визуально пересекает метаданные. В галерее задние карточки дают глубину, но подписи пересекаются. В орбитальной секции основной заголовок читается хорошо; мелкое описание около иконки теряется. Фиолетовый вариант заметно интенсивнее ночного — стоит сохранить его как альтернативу, а не усиливать насыщенность ещё больше.

## P0 — композиция и чтение

**Раскрытая карьера.** Асимметрия — у внешнего стекла, прямоугольная спокойная сетка — у контента. Внутренние поля desktop 44–56 px, mobile 22–24 px. Шапка: логотип 40–48 px, компания 28–36 px, роль 13–14 px; закрытие в отдельной зоне 44 × 44 px. Далее сетка 56/44 с зазором 28–36 px: слева изображение 4:3 или 16:10, справа содержательный лид 24–30 px и 2–3 коротких абзаца 15–17 px / 1.5. Строка дат только одна. Под первым разворотом — два доказательства работы с подписями, доступные нормальной вертикальной прокруткой; затем следующий кейс. Не придумывать численные результаты: показывать подтверждённые обязанности, решения и артефакты.

За текстом — локальная дымчатая подложка `#101720` с альфой 0.70–0.82. Блик проходит по пустому краю, не по строкам. Размытие и fade не должны накрывать основную информацию или последнее изображение. Содержательный текст `#e6ebf2`, вторичный `#b6c2d0`; проверять контраст уже на итоговом фоне.

**Галерея.** Предпочтительно оставить текущую колоду только одному проекту. Остальные: (1) редакционный разворот «одно крупное изображение + два малых», (2) вертикальные главы с фиксированным коротким заголовком, (3) контактный лист 2 × 2 с раскрытием. Выбор зависит от материала: процесс → главы, вариации → контактный лист, цельный продукт → разворот. На mobile всё становится последовательностью блоков. Не менять механизм навигации в каждой главе.

## P1 — материал и движение

**Загрузчик: пять пар, по два предмета одновременно.** Предметы слева/справа от неподвижного процента, зеркальна только позиция, не обязательно геометрия. Предложения для собственных ассетов:

1. Кобальтовая смятая звезда / серебряный мягкий куб.
2. Коралловый органический узел / лиловое кольцо.
3. Лаймовая стеклянная капля / синяя металлическая лента.
4. Перламутровая раковина / розовый надутый цветок.
5. Серебристый астериск / дымчато-фиолетовая галька.

Свет общий: крупный мягкий источник сверху слева, тёмный нижний край, один узкий блик. Акценты `#7b83ff`, `#c5b5eb`, `#d69da7`, `#c3d293`, `#dce6f0`. Размер каждого desktop 120–170 px, mobile 64–90 px. Между предметом и цифрой минимум 36 px, mobile 18 px.

Цикл пары 1.15–1.45 s: первые 24% scale .28→.94 и opacity 0→1; средние 48% scale .94→1.08, поворот до 4°; последние 28% scale 1.08→1.17, opacity 1→0, blur 0→9 px. Кривая появления `cubic-bezier(.16,1,.3,1)`, исчезновение `cubic-bezier(.4,0,1,1)`. Перекрытие соседних пар 100–140 ms. Не задерживать готовый сайт ради обязательного показа всех пяти пар: все пары доступны в ручном предпросмотре загрузчика. Размывать только маленькие предметы, не весь экран. Reduced motion: статическая пара и короткий fade.

**Частицы.** 14–22 на desktop, 6–10 mobile; диаметр 1–2.5 px, альфа .10–.28, движение 12–26 s с амплитудой 14–30 px. Холодные, изредка слегка тёплые. Два слоя, без соединительных линий и реакции на курсор. CSS transform/opacity или один небольшой canvas; без отдельных WebGL-проходов, без blur всего viewport. Останавливать вне видимой сцены и при скрытой вкладке.

**Орбитальные иконки.** Scale 1→1.05 за 650–800 ms, easing `cubic-bezier(.2,.7,.2,1)`; иконка не должна одновременно резко поворачиваться и двигаться. Текущие 1.12 уменьшить. Название 12–13 px, описание 11–12 px, максимум две строки и 160–190 px ширины. Описание объясняет действие или идею («Исследование векторизации», «Словесная игра на шестиугольниках»), а не просто категорию. Один hover/focus выводит одну подсказку; на touch описание видно у выбранного объекта. Убрать дублирующий плавающий preview, если он закрывает соседей.

## P2 — типографика и детали

**Заголовки.** Точное имя в hero и его оформление сохранить. Остальным секциям прежде всего дать иерархию существующей гарнитурой; альтернативный шрифт — один на весь сайт, после проверки лицензии и кириллицы. Не масштабировать шрифт по Y: натуральные пропорции выглядят спокойнее. Serif italic оставить только короткому эмоциональному акценту, не метаданным.

**Marquee.** 26–36 px desktop, 20–24 px mobile, круглые разделители 10–12 px и интервалы 30–40 px. Плавный вертикальный сатиновый градиент `#788ba3 → #c4d1e2 → #8799ad`, без частой яркой полосы и дополнительного мерцания. Скорость ориентировочно 18–25 px/s; края растворяются на 10–14% ширины. Достаточно движения ленты: анимация света необязательна.

**Приглашение к скроллу.** Одна тонкая линия 34–42 px, точка 3 px и читаемая подпись 11–12 px; сдвиг точки 7 px за 2.4 s. Вся зона нажимаемая 44 px высотой. Исчезает после начала прокрутки. Это яснее нескольких конкурирующих стрелок.

**Декоративный текст и даты.** Запрошенное увеличение ×1.6 применять к декоративным подписям hero/таймлайна, сохраняя поля и переносы. Выбранная дата: размер ×1.08–1.12, вес +100, яркость .9 вместо .5; переход 350–450 ms без прыжка соседних дат. Превью карьеры: компания + роль + одна конкретная зацепка в 5–9 слов; изображение по наведению не заменяет эту информацию.

## Что убрать в первую очередь

- Дублирование годов, микротекст 7–8 px, технические служебные подписи в основной композиции.
- VIEW поверх содержимого и обрезанные полупрозрачные подписи задних карточек.
- Повтор одной горизонтальной галереи для всех проектов.
- Постоянное движение сразу частиц, бликов, marquee и всех иконок с одинаковой заметностью.
- Новые дорогие шейдеры: текущему сайту сейчас полезнее спокойная композиция, чем ещё один эффект.
