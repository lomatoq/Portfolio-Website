# Дизайн и проверка — 17 сентября

Рабочая версия: `index.html`, пересобирается командой `python rebuild.py` из 19 исходных блоков.

- Контакт: единая пара Discuss a role + круглый CV. CV намеренно отключён по просьбе владельца до появления резюме. Заполнение ограничено круглой маской, отдельное место в мобильном footer.
- Типографика: загруженные Syne для названий, Space Grotesk для интерфейса и описаний; JetBrains Mono для технических меток. Сохранены фирменные декоративные serif-заголовки.
- Hover: плавный scale/lift, подсветка названия, последовательное появление слов из blur. На desktop описание в центре орбиты; на mobile — в свободной области заголовка.
- Река следует выбранной карточке, конец свечения ограничен её позицией. Энергия стрелки обрезана её контуром.
- Частицы: небольшой WebGL point-sprite shader серебристых волокон с изгибом и движущимся бликом, 12 на mobile / 28 на desktop, отключён в reduced-motion и экономичном режиме.
- Popup: до 1320px, затемнение, рабочая кнопка сворачивания, управление фокусом, обратимый переход без геометрического скачка.
- Галереи: убраны сильный наклон, раскачка и перекрывающиеся стопки. Для технических проектов — спокойная горизонтальная последовательность, для персонажей и материалов — небольшое изменение глубины.
- В индексе последнее выбранное произведение сохраняет светлую боковую линию и спокойную градиентную подложку.

## Независимые проверки

Три агента участвовали в реализации и проверках. Размеры 1920, 1440, 390, 320px: без JS/shader ошибок и горизонтального переполнения. Клик по сворачиванию проверен на каждом размере; Escape во время открытия и reduced-motion также проверены. Степень рассогласования реки с выбранной карточкой после остановки <3px. На переходе обратно в исходную карточку измеренный скачок геометрии <0,05px.

Короткая финальная выборка Chrome/WebGL2: p95 интервала кадров 16,6–20,9ms, без кадров >50ms в этой выборке. Это локальный замер, не гарантия на всех устройствах. Более ранний параллельный прогон показывал отдельный кадр 70,6ms.

Повторная мобильная проверка: зазор между навигацией и контактом 4px, между ссылками footer и контактом около21px. Полные hover-описания не пересекаются с иконками. Синяя тема проверена отдельно, включая hover кнопки и энергию стрелки.

Результаты: `../experimental-qa/independent26.json`, `contact26-fresh.json`, изображения `orbit26-*`, `contact26-*`.
